# Catálogo de fontes oficiais para lotes massivos — FHEMIG 2023

Este índice preserva a seleção de **43 cadernos Tipo 1**, com links de origem e gabarito definitivo. Ele **não contém os enunciados nem alternativas** das provas de terceiros; portanto, **nenhuma questão nova é adicionada ao banco por este arquivo**.

O roteiro de extração anterior identificou **572 candidatas** após filtros técnicos preliminares, mas a publicação dos textos foi bloqueada, e essa cifra não deve ser confundida com questões importadas. A classificação clínica baseada somente no cargo é provisória e precisa ser conferida por tema de cada questão.

Antes de incorporar textos integrais, confirmar permissão de reprodução, legibilidade das alternativas, gabarito definitivo, questões anuladas, imagens necessárias, disciplina/assunto correto, e duplicidade semântica. Utilizar o importador oficial do projeto com manifestos `cortex-questoes-oficiais-v1` de até 1.000 questões cada.

Gabarito: https://conhecimento.fgv.br/sites/default/files/concursos/gabarito-definitivo-fhemig-retificado-01.11.2023.pdf

Arquivos de índice pertencem a `backend/data/catalogos-fontes/`, **fora** de `backend/data/questoes-oficiais/`, para não dispararem importação automática de metadados.
